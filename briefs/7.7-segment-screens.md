# 7.7: Segment screens

| | |
|---|---|
| Id | 7.7 |
| Crates or packages | `web/app` |
| Depends on | 7.6, 5.7 |

## Goal

The screens for segments: a segment index and detail beside the route screens, authoring a segment draft on the same canvas used for routes, inserting a segment into a route draft or a journey from the canvas and node detail with role and kind mapping and edges to the graph it joins, upgrading an insertion through proposal review, and saving a selection as a segment.

## Governing

- PRD: C19, C14 (insert, upgrade, and save as segment go through review), C17 (the route screens these mirror), A12 (authoring on the canvas), B13, B14, B15, C1 and C8 (provenance and insertion shown on nodes).
- ARCHITECTURE: Web UI (Screens).
- PRACTICES: Code conventions (TypeScript).

## Scope

In:

- The segment index and segment detail, which lists each version with the insertions on it and flags those with an upgrade available.
- Segment drafts on the authoring canvas, with publish and retire.
- An "insert segment" flow from the canvas and node detail: pick the segment, version, and parent; map roles and kinds; add edges. It is reviewed as a proposal.
- Insertion upgrades from node detail and from segment detail.
- "Save as segment" from a canvas selection, with B15's review.
- Node detail and the canvas show which insertion a node came from, and its provenance.

Out: changes to proposal review beyond the new item types it shows.

## Acceptance

- Behavior by id: C19, C14 (each flow's items appear and apply), B13, B14, B15 (driven through the screens over 7.6's fixture).
- Playwright: insert the fixture segment twice into a journey, mapping one role onto an existing role and adding an edge, and see both insertions on the canvas; publish a new segment version and upgrade one insertion, keeping a local edit; save a selection as a new segment and see it in the index.
- Planted bug: send the insertion and its edges as two patches, and show the one-patch test fail.

## Decisions left to the implementer

- Whether the insert flow maps roles inline or as a step of the review.
