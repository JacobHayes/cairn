# 6.1: Multiplayer testbed

| | |
|---|---|

## Goal

Simulation track: exploratory and non-blocking (README, Order). Many virtual clients issuing patches to one journey through faults, using the real H5 retry, checking that every acknowledged patch is visible, none is applied twice, revisions are gap-free, replay equals state, and every view catches up (H6).

## Governing

- PRD: H5, H6, A17, I6 (duplicate proposal submission by id), J2, J3.
- PRACTICES: Simulation with `patina` (Testbeds; the honesty rules).
- ARCHITECTURE: Storage > Concurrency and notification.
- 1.3's decision on whether clients drive the real HTTP server or call the service in-process.

## Scope

In: a `main` building a `Service` on the Turso store and serving 4.2's router on one current-thread tokio runtime, N clients as tasks on that runtime with 4.2's retry and subscription logic over HTTP and SSE (1.3 chose the real server, with conditions: [`decisions/2026-10-06-6-1-drives-the-real-http-server-on-one-current-thread.md`](../decisions/2026-10-06-6-1-drives-the-real-http-server-on-one-current-thread.md); `testbeds/spike/README.md`), `always!` for each invariant, including every subscriber reaching the store's revision within the coalescing interval after writes stop; `sometimes!` for a retried conflict, a surfaced overlapping conflict, a coalesced tick, and a deployment tick after an entity merge; a README.

Out: durability faults (6.2).

## Acceptance

- A campaign over the local seed count passes with every `sometimes!` fired.
- Planted bug: break the revision check, get a failing seed that minimizes to the conflict, and rewrite it as an ordinary test in the service's tests.

## Decisions left to the implementer

- Client behavior mix, N, virtual duration, fault rates.

## Decision log

Appended by the implementer.

- Planted bug: Turso's commit-time revision check skipped for the target domain (`if index > 0 && now != expected` in `check_revisions`). The smoke campaign failed 11 of 16 generations on `acknowledged-visible` (two patches acknowledged at one revision); `cargo patina minimize --generation 3 --no-trace-phase` reduced generation 3 to `--buggify-activation-permille 655` (the `store-commit-waits` site holding a commit before it began while another that loaded the same revision landed); rewritten as `a_patch_that_loses_the_race_to_commit_is_rejected_stale_{memory,turso}` in `crates/service/tests/in_flight.rs`, which failed on Turso with `expected a stale answer, got Ok(Applied { .. })`; plant removed, it passes.
- Client mix: four HTTP clients and one in-process agent, eight patches each a seeded 0 to 20 ms apart: 40% notes (never overlap), 60% renames of one of three nodes (overlap often), and one entity merge by client 0 halfway through. Virtual duration is whatever that takes (about 0.1 to 0.6 s).
- Faults: the explicit-knob sweep in `sim.sh` keeps the spike's rates (drop, refuse, reset 100 per mille; 1 ms latency; jitter to 2 ms). The campaign draws buggify rates per generation; long store faults are rationed per run (four waits, one stall) so a run stays under patina's trace event limit.
- Timeouts: 200 ms per attempt, 5 ms backoff, 64 attempts (the spike's 40 ms was too short once commits can be held); long store faults hold 400 ms, past the attempt timeout.
- The brief asks for an `always!` per invariant; each is a `violation` verdict instead, since an `always!` abort leaves no replayable trace ([`decisions/2026-10-06-patina-an-always-violation-leaves-no-trace-to-replay.md`](../decisions/2026-10-06-patina-an-always-violation-leaves-no-trace-to-replay.md), patina gap 6).
- I6 (duplicate proposal submission) is not exercised: proposal endpoints land with 4.9.
- Edits outside `testbeds/multiplayer`: `crates/store` (`CommitPoint::BeforeBegin`, paused in the memory backend's commit) and `crates/store-turso` (the same pause), `decisions/`; `crates/service/tests/in_flight.rs` (the regression tests) and its dev-dependency on tokio's `sync` feature; the oracle labels in `crates/service/src/write.rs` and `crates/api/src/client/retry.rs`, renamed in kebab-case (patina gap 5); PRACTICES' multiplayer bullet. `mise run sim` and the nightly CI job pick the testbed up through its `sim.sh` unchanged.
