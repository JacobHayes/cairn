# 4.5: Wasm host: engine package, derive worker, in-browser root

| | |
|---|---|
| Id | 4.5 |
| Crates or packages | `crates/wasm`, `web/wasm` |
| Depends on | 4.2 |

## Goal

The browser as a first-class host: the engine and service compiled to wasm, deriving each domain document locally in a worker, and the in-browser root that runs the whole service over the memory store with no server, for UI development, demos, and end-to-end tests.

## Governing

- PRD: I1; Non-functional: Small-team scale.
- ARCHITECTURE: Web UI (data flow, version skew, in-browser host); Repository layout (`crates/wasm`, `web/*`); Storage > Backends (Memory); Generated artifacts.
- PRACTICES: Code conventions; The validation ladder (rungs 5 and 6).

## Scope

In: `crates/wasm` exports for every host (`derive`, `apply`, every projection, `explanations`, the touched-set function, import and export, `preview`) and the in-browser root (service, memory store seeded from the fixtures, in-process notifier, one local identity); `web/wasm/generated/` plus the hand-written loader and the derive worker; the engine-version check a host reads before deriving, previewing, or writing.

Out: the client wrapper and app shell (4.6); every screen (phase 5); persistence and cross-tab sync in the in-browser host (none by design).

## Acceptance

- Wasm `derive` of every fixture, in the worker, equals the server's derive byte for byte; every projection and `preview` agree likewise.
- The in-browser root loads each fixture, applies a patch, rejects a stale one, and notifies its subscribers.
- The engine-version check refuses a document from another engine version. The derive benchmark at the limits is repeated in the browser and reported in the proof as a table.
- Planted bug: return the server's derive from a cache keyed without the deployment revision and show the byte-equality test fail after an entity edit.
- Adds rung 6 with these browser tests.

## Decisions left to the implementer

- The wasm packaging tool; how the worker and the main thread share the document.
