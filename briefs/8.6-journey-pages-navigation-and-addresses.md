# 8.6: Journey pages, navigation, and addresses

| | |
|---|---|
| Id | 8.6 |
| Crates or packages | `web/app` |
| Depends on | 8.4, 8.1 |

## Goal

Replace a journey's nine tabs with two pages chosen by intent. The Next page answers "what can be done now" (list and cards), the Plan page answers "what does the whole thing look like" (graph, list, and timeline), and one switcher in one place picks the projection. What the overview and summary tabs held becomes the journey header and a journey card in the detail column whenever nothing is selected, which opens to a full Summary page. Every old address still lands somewhere sensible.

## Governing

- PRD: C10, C11, C12 (the pages and the decisions filter), C16 (journey index, overview as the journey card, entry points in the header), C18 (the Summary page), B11 (lifecycle moves), C9 (the filters), Users (participants first).
- ARCHITECTURE: Web UI (Screens, Addresses).
- DESIGN: Approachable by default (quieter chrome); Components (Segmented control, Popover and menu); Layout.
- PRACTICES: Code conventions.

## Scope

In:
- The journey header, one line: the title, a pending-proposal chip when one exists (it opens review), the lifecycle chip (its menu lists only the moves allowed now: complete, reopen, archive, unarchive, delete), and an overflow menu: Edit structure, Select (8.8), Insert segment (when 7.7 has landed), Upgrade (listed only when one is available), Save as route, Save as segment (when 7.7 has landed), Re-link, Summary, Copy link, each wired to the existing flows. Bands under it only when they apply: archived (read only), completed (with Reopen), and suggested completion (with Complete journey). The "derived in this tab at revision" sentence leaves every header (8.5 moves it into the sync chip's popover).
- The toolbar: the page tabs Next and Plan with counts (the acting frontier; nodes in scope), a Decisions toggle (key `d`), one Filter button holding Mine (key `m`; left out when the viewer holds no participation), kind, owner, and the flags, with a count when anything inside is on, search (key `/`), and the switcher at the right end in one global order (Graph, List, Timeline, Cards; each page shows its subset, never a disabled segment; key `v` cycles). Active filters show as removable chips under the toolbar. On graph and timeline a filter fades; on list and cards it hides.
- Addresses: `/journeys/<id>/next/{list|cards}` and `/journeys/<id>/plan/{graph|list|timeline}`, each with `/nodes/<key>` (and `/edges/<from>~<to>` on the graph); `/journeys/<id>/summary`; filters, detail step, open and shut containers, and the signals lens in the query. A journey opens on Next with cards and the decisions filter on its first visit (C11), otherwise Next as a list. A bare `/journeys/<id>/nodes/<key>` opens on the Next list when the node is on the acting frontier, otherwise on the Plan graph, revealed, centred, and selected. Each viewer's last projection per page is remembered per journey (browser storage, guarded).
- Redirects from every old address: the canvas (with its kind, drill-in, relevance, and heat parameters mapped to a kind filter, an open container, the display states shown, and the gravity lens), overview, next, list, triage, walkthrough (Next cards with decisions on), decisions (Plan graph with decisions on), timeline, summary, node addresses on any of them, and `/routes`.
- The journey card (the detail column's empty state on both pages): status, progress, at most three next-up items and the next milestone; the flags as one short sentence ("2 overdue, 1 stale") only when any is non-zero, each a link to the Plan list with that filter; description, notes and links, open decisions, upcoming milestones, and lineage (version, upgrade available, re-link) folded. Expanding it opens the Summary page: the same component at full width with every fold open, plus counts by display state.
- The journey index as a primary table: name, status, progress (done and skipped over in scope, by display state), next milestone, and one flag (stalled, overdue, stale, or upgrade available, plus a count of others), with filters for status, route, mine, and upgrade available. The Library index (routes now; segments join it with 7.7).
- Removal of the Overview, Summary, and Decisions pages; until 8.7 lands, the decision view's affects table moves unchanged into the decision's detail, so nothing is lost. The shared end-to-end page objects move to the new addresses.

Out: print styles for the Summary page (later, additive); the projections' contents (8.8 to 8.10); Mine (8.9).
