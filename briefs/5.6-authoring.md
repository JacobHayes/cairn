# 5.6: Authoring: structure editing on the canvas and in node detail

| | |
|---|---|
| Id | 5.6 |
| Crates or packages | `web/app` |
| Depends on | 5.5 |

## Goal

Everything a person does by hand to change a graph's structure, for a route draft and a journey alike: add, edit, move, and remove nodes; draw and delete edges; roles, participation kinds, and `default_owner`; conditions, date rules, stage bounds, weights, estimates, flags, decision prompts and choices, and resources; breakdown by hand; local edits and reset; the removal cascade. Every edit is previewed with the wasm engine and sent through 4.6's write path, with rejections shown at the field.

## Governing

- PRD: A1, A1a, A2 to A8, A10, A12 (the by-hand path), A15, A16, A18, B4, B10, Identity and references, Invariants; Non-functional: Config-first.
- ARCHITECTURE: Web UI (Previews, Canvas); Engine > Conditions.
- PRACTICES: Explicit limits (each editor enforces its limits before sending).

## Scope

In: edit mode on 5.2's canvas (a toggle on a journey, always on for a draft); `NodeForm`, `ConditionEditor`, `DateRuleEditor`, `StageBoundsEditor`, `RolesAndKindsPanel`, `ResourceEditor` (placeholders picked, stored as key references), `CascadeDialog`, exported for 5.7; local-edit markers with reset and tombstones with restore; breakdown by hand and mark atomic.

Out: date pins and conflict resolution (5.1), proposal review (5.7), the assistant (5.8).

## Acceptance

- Behavior by id: A1a (a kind's form offers exactly its fields), A3 (an ancestor or descendant edge is refused with the reason), A5 (every operator reachable; a type mismatch cannot be entered), A8, A12 (a route authored by hand exports to a file that re-imports to the same graph), A15 (three violations at three fields), A18, B4, B10, Identity and references (renaming a node referenced by a condition leaves it intact).
- Playwright on the in-browser host: author a small route from an empty draft (two decisions, a stage, three deliverables with a condition and a date rule, a milestone, a role with a filling decision), publish, export; on a fixture journey, add a local node, edit and reset a route-copied title, remove a node with a dangling condition and resolve the cascade.
- Planted bug: send a removal without its cascade and show the A18 test fail.

## Decisions left to the implementer

- Palette or context menu, inline or panel forms, drag affordances; whether journey edit mode is a toggle or its own path.
