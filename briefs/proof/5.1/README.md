# Proof for brief 5.1: Node detail and explanations; notes, links, artifacts

A node now opens into a detail panel that explains it: why it is relevant, what blocks it,
where each date comes from, what makes up its priority, and who takes part. From the same
panel you can pin dates, fix a contradictory pin in one click, add notes and links, and
complete work with an artifact.
