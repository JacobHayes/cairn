# Proof: brief 6.2, durability testbed

Generated by `briefs/proof/6.2/prove.sh`; do not edit by hand. Every run is the
testbed (`testbeds/durability`) built with `cargo patina build` and run under the patina
native shim: the service on the real Turso store in a simulated filesystem, one client
submitting a 24-step seeded plan and keeping a durable ledger of what was acknowledged.
After every restart and at the end the run checks that no acknowledged commit is
missing, that each commit is whole or absent, that the log holds only what was
submitted, and that the state loaded equals the engine's replay of the log.
