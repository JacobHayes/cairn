# Decisions awaiting review

Judgment calls made while implementing the briefs, for the user to review (`AGENTS.md`, Decide, record, keep going). One file per decision, so entries never conflict and nothing indexes them: `ls decisions/` lists them oldest first, by date.

To add one, create `decisions/YYYY-MM-DD-<short-slug>.md` (the date of the call; a slug of a few words from the title, adding `-2` if the name is taken) holding a `# title` and then the question (naming the brief), the call, the alternatives, and what would change it. Keep a tag like `[patina]` or `[turso]` in the title for calls about those projects. Point at an entry by its file name.
