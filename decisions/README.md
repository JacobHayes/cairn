# Decisions

Judgment calls made while working on Cairn, for the user to review (`AGENTS.md`, Decide, record, keep going). One file per decision, so entries never conflict and nothing indexes them.

To add one, create `decisions/YYYY-MM-DD-<short-slug>.md` (the date of the call; a slug of a few words from the title, adding `-2` if the name is taken) holding a `# title`, then the question, the call, the alternatives, and what would change it. Tag the title with `[patina]` for calls about that project. Point at an entry by its file name.

Every file holds a call that is still in force. When a later call replaces one, delete the old file in the same change; when what a call governs is removed, delete the call.
