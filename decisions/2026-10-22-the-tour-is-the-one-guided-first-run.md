# The tour is the one guided first run

Question: the tour of Cairn is a guided first run. How is it drawn, so that it teaches without taking the screen away?

Call: the tour is built from what the app already has: a band in the layout above the screen (as the proposal band is), compact on a phone so the screen keeps room for the action being taught, standalone panels where there is no target, the ordinary selection for nodes, and a static dashed outline on the one or two controls a step names. No floating cards anchored to controls, no dimming, no arrows, no timed or animated hints. Those keep the screen usable while it teaches, and are what the person will meet again once the tour is over.

Alternatives: anchored popovers with accent rings (they cover controls, need measuring, and look like keyboard focus); a dedicated practice screen outside the shell (a reduced app shown to the person); no tour (misses the discovery a new person needs).

What would change it: a second guided flow being asked for, which would make the band a shared component.
