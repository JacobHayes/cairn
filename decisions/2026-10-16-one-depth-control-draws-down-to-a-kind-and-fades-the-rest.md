# One Depth control draws down to a kind, and Fade dims the rest

Question: what is the one control for how deep a view draws, and what does it mean on each view?

Call: Depth is a ladder of four steps named for the deepest kind each draws (Stages, Decisions, Deliverables, Actions), shared by every view and always applied through the engine's level request, so roll-ups and the hidden-prerequisites mark hold at every step. Each step adds the next layer down. Fade, an option in the Depth menu, draws everything and dims exactly what Hide would not draw at that depth. Frontier dimming and Depth dimming combine as a union, never multiplied. At Decisions the walkthrough walks decisions only, so a new journey's walkthrough never opens on a milestone.

Alternatives: per-kind checkboxes (kinds nest, so an arbitrary set such as hidden parents with shown children means nothing); dimming by kind under Fade (it would disagree with what Hide leaves out).

What would change it: journeys so large that Stages still draws too many cards, which would need a roll-up step above it.
