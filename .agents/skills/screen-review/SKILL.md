# Screen review

**Publish.** From a screenshot set (the output of `mise run screenshots`, or a proof's media), build one page: a section per screen, its states side by side at desktop and phone widths, light and dark a toggle away, each image captioned with what it shows and where it is in the app. Publish it where the host lets reviewers comment (the host's own instructions say how), watch it for comments, and give the owner the link.

**Resolve.** Read every thread before changing anything, and group threads that share a cause. Fix causes, not pictures, by the repository's own rules for changes and screens. Answer each thread with what changed and a fresh screenshot, or why not; a call with several reasonable answers gets a mockup of each and your recommendation. Resolve a thread only once it is answered, and republish with the new screenshots.
